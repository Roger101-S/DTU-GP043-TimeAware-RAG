# Third-party credits

## Ideas this project builds on (no code copied)
* **Emmimal/temporal-rag** (https://github.com/Emmimal/temporal-rag, MIT). A post-retrieval temporal layer
  (validity filtering, exponential time decay, supersession chains). The soft time-decay baseline in
  `src/baselines.py` uses the same standard half-life decay idea; the implementation here is our own and was
  written from the project's public README, not from its source files.
  **If you copy any code from that repository, include its LICENSE file with its copyright line next to the copied
  code and mention it in the report.**
* **Self-RAG** (Asai et al., 2024), **CRAG** (Yan et al., 2024) and LangChain's LangGraph tutorials for the
  grade-then-route pattern behind the arbitration graph.
* **TIMER** (Cui et al., 2025), **EHR-RAG** (Cao et al., 2026), **RASTeR** (Schumacher et al., 2025), **DoctorRAG**
  (Lu et al., 2025), **MIRAGE** (Xiong et al., 2024): related work cited in the research plan. No code from them is
  included.

## Libraries (installed separately, each under its own licence)
spaCy, dateparser, ChromaDB, LangGraph / LangChain, sentence-transformers, NumPy, python-dotenv, pytest.
